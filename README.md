# 🩺 nobat_checker

**بررسی اولین نوبت آزاد و ظرفیت باقیمانده در سامانه نوبت‌دهی اینترنتی دانشگاه علوم پزشکی تهران**
([nobat.tums.ac.ir](https://nobat.tums.ac.ir/)) — بدون نیاز به نصب هیچ نرم‌افزار اضافه‌ای.

این برنامه صفحه هر پزشک را بررسی می‌کند، **اولین تاریخِ دارای نوبت آزاد**، **تعداد ظرفیت باقیمانده** و
**ساعت‌های آزاد** را پیدا می‌کند و به شما خبر می‌دهد — با زنگ ترمینال، اعلان (Toast) ویندوز و باز شدن خودکار صفحه پزشک.

---

## ⭐ امکانات

- ✅ نمایش **اولین نوبت آزاد** با **تاریخ شمسی**، **ظرفیت باقیمانده** و **ساعت‌های آزاد**
- ✅ پشتیبانی از **چند مرکز/خدمت** برای هر پزشک (مثل بیمارستان رازی + مجتمع امام خمینی)
- ✅ حالت **پایش مداوم** (`-Watch`) — هر چند دقیقه خودکار بررسی می‌کند
- ✅ **هشدار چندگانه**: زنگ + اعلان ویندوز + باز شدن خودکار صفحه رزرو در مرورگر
- ✅ پشتیبانی از **چند پزشک همزمان** با فایل `doctors.txt`
- ✅ بدون هیچ پیش‌نیازی — فقط PowerShell داخلی ویندوز (۵.۱ به بالا، در همه ویندوزهای ۱۰ و ۱۱ موجود است)
- ✅ ثبت گزارش (لاگ) اختیاری
- ✅ کار با هر سامانه‌ای که با موتور **بایوویزیت (BioVisit)** کار می‌کند (با پارامتر `-BaseUrl`)

## 🚀 اجرای سریع (ویندوز)

### قدم ۱ — دانلود

دکمه سبز **Code** بالای همین صفحه → **Download ZIP** → فایل را Extract کنید.

### قدم ۲ — اجرا

پوشه پروژه را باز کنید، در نوار آدرس پوشه بنویسید `powershell` و Enter بزنید
(پنجره PowerShell در همان پوشه باز می‌شود) و دستور زیر را اجرا کنید:

```powershell
powershell -ExecutionPolicy Bypass -File .\nobat_checker.ps1 -Account 10460
```

عدد `10460` شناسه صفحه پزشک است (بخش `/book/account/10460` از آدرس صفحه پزشک).

نمونه خروجی:

```
  ==============================================================
   پزشک                : دکتر صفورا شکوئی نژاد
   شناسه صفحه          : 10460
   تاریخ اولین نوبت    : شنبه, 2 آبان 1405  (2026-10-24)
   ظرفیت باقیمانده     : 7
   ساعت‌های آزاد        : 07:00  ،  08:00
   نوع نوبت            : سامانه نوبت‌دهی اینترنتی
  ==============================================================
```

## 📖 راهنمای کامل پارامترها

| پارامتر | توضیح | پیش‌فرض |
|---|---|---|
| `-Account` | شناسه یا لینک کامل صفحه پزشک (چند مقدار با کاما) | — |
| `-DoctorsFile` | مسیر فایل متنی حاوی فهرست پزشکان (`doctors.txt`) | — |
| `-Watch` | حالت پایش مداوم؛ بعد از هر بررسی، دوباره بررسی می‌کند | خاموش |
| `-Interval` | فاصله بین بررسی‌ها در حالت پایش (ثانیه) | `300` |
| `-Days` | چند روز جلوتر را جستجو کند | `60` |
| `-BaseUrl` | نشانی سامانه نوبت‌دهی | `https://nobat.tums.ac.ir` |
| `-NoBrowser` | هنگام پیدا شدن نوبت، مرورگر باز نشود | — |
| `-NoToast` | اعلان ویندوز غیرفعال شود | — |
| `-NoBeep` | صدای زنگ غیرفعال شود | — |
| `-LogFile` | مسیر فایل گزارش برای ثبت نتایج | — |

### نمونه‌های کاربردی

```powershell
# یک بررسی ساده از پزشک با شناسه 10460
.\nobat_checker.ps1 -Account 10460

# پایش مداوم هر ۵ دقیقه (وقتی نوبت پیدا شد، زنگ + اعلان + باز شدن مرورگر)
.\nobat_checker.ps1 -Account 10460 -Watch -Interval 300

# پایش هر ۳ دقیقه با لینک کامل پزشک و ثبت گزارش در فایل
.\nobat_checker.ps1 -Account "https://nobat.tums.ac.ir/book/account/10460?lang=fa" -Watch -Interval 180 -LogFile result.log

# بررسی چند پزشک با هم از فایل doctors.txt
.\nobat_checker.ps1 -DoctorsFile doctors.txt -Watch -Interval 240

# بررسی بدون باز شدن مرورگر و بدون اعلان (فقط نمایش در ترمینال)
.\nobat_checker.ps1 -Account 10460 -NoBrowser -NoToast -NoBeep
```

## 📋 فایل doctors.txt

برای پایش چند پزشک با هم، مسیر فایل را با `-DoctorsFile` بدهید. هر خط یک شناسه یا لینک؛ خط‌های
با `#` نادیده گرفته می‌شوند (نمونه: [`doctors.txt`](doctors.txt)):

```text
# فهرست پزشکان — هر خط یک شناسه یا لینک کامل
10460
# https://nobat.tums.ac.ir/book/account/10460?lang=fa
12345
```

## 🔍 چطور شناسه پزشک را پیدا کنم؟

1. در سایت [nobat.tums.ac.ir](https://nobat.tums.ac.ir/) پزشک یا مرکز موردنظر را باز کنید.
2. آدرس صفحه چنین شکلی دارد: `https://nobat.tums.ac.ir/book/account/10460?lang=fa`
3. عدد بعد از `account/` همان شناسه است (اینجا: `10460`). یا کلاً همان لینک را به برنامه بدهید.

## ❓ پرسش‌های پرتکرار

**آیا چیزی باید نصب کنم؟**
خیر. اسکریپت فقط از امکانات داخلی ویندوز استفاده می‌کند (PowerShell 5.1 به بالا، روی ویندوز ۱۰/۱۱ به‌صورت پیش‌فرض موجود است).

**خطای «running scripts is disabled» گرفتم!**
به‌جای اجرای مستقیم، از دستوری که در «اجرای سریع» آمده استفاده کنید؛ پارامتر
`-ExecutionPolicy Bypass` فقط برای همان یک اجرا است و تنظیمات سیستم شما را تغییر نمی‌دهد.

**پیام خطای 403 یا Access Denied دیدم!**
سایت نوبت‌دهی فقط از IP ایران پاسخ می‌دهد. اگر VPN دارید خاموشش کنید و دوباره اجرا کنید.

**چند وقت یک‌بار بررسی انجام شود؟**
در حالت پایش، فاصله ۱۸۰ تا ۶۰۰ ثانیه منطقی است. فاصله‌های خیلی کوتاه باعث فشار به سرور
سامانه و احتمال مسدود شدن IP شما می‌شود؛ لطفاً محترمانه استفاده کنید.

**آیا برنامه خودش نوبت را رزرو می‌کند؟**
خیر. برنامه فقط «پیدا کردن» می‌کند و صفحه پزشک را برایتان باز می‌کند تا خودتان سریع رزرو کنید
(رزرو نیاز به ورود به حساب کاربری و پرداخت دارد).

**برای سامانه‌های دیگر (دانشگاه‌ها/کلینیک‌های دیگر بایوویزیت) هم کار می‌کند؟**
بله؛ با پارامتر `-BaseUrl` نشانی سامانه دیگر را بدهید، مثلاً:
`-BaseUrl https://biovisit.ir`

## 🛠 نحوه کار (خلاصه فنی)

برنامه دقیقاً همان درخواست‌هایی را می‌زند که مرورگر شما موقع باز کردن صفحه پزشک می‌زند:

1. دریافت صفحه `/book/account/<شناسه>?lang=fa` و استخراج پارامترهای هر مرکز/خدمت (`uid`, `cid`, `wid`, `service_id`)
2. فراخوانی اندپوینت `/time/source?lang=fa&...` برای بازه زمانی «۷ روز قبل تا N روز بعد»
3. فیلتر موارد `is_full`، نوع `unknown` و ظرفیت صفر از میان `first_time`ها و انتخاب نزدیک‌ترین تاریخ
4. نمایش نتیجه و (در صورت فعال بودن) هشدار زنگ + اعلان ویندوز + باز شدن مرورگر
